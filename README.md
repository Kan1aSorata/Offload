# Offload

插入相机存储卡，照片和视频自动备份到你的 SSD，校验通过后自动弹出卡。

Insert a camera card — Offload backs it up to your SSD, verifies every file, and ejects the card.

## 特点

- **全自动**：常驻菜单栏，插卡后全程不用点
- **只拷新文件**：同一张卡再插一次，只备份上次之后新拍的
- **逐个校验**：每个文件写完都从 SSD 读回来比对，全部通过才弹卡
- **按日期归档**：自动整理成 `年/月/日` 文件夹，也可以按相机型号或卡名
- **不动原卡**：只读存储卡，绝不修改或删除卡上的文件

## 安装

1. 从 [Releases](https://github.com/Kan1aSorata/Offload/releases) 下载最新的 `Offload.dmg`
2. 打开后把 Offload 拖进「应用程序」
3. 需要 macOS 12 或更高版本，支持 Apple Silicon 与 Intel 芯片

## 使用

1. 首次打开时，选择用来存放备份的 SSD 和文件夹
2. 插入相机存储卡，菜单栏图标会显示备份进度
3. 完成后会收到通知，卡已自动弹出，可以直接拔下

备份后的目录长这样：

```
Cards/
└── 2026/
    └── 10/
        └── 20/
            ├── DSC01234.ARW
            ├── DSC01234.JPG
            └── C0070.MP4
```

## 常见问题

**插卡后「照片」App 也弹出来了？**
打开「图像捕捉」，选中相机卡，把「连接此设备时打开」设为「无」。

**第一次插卡时系统询问是否允许访问「可移除宗卷」？**
请点「允许」，Offload 需要读取存储卡。文件只在本机复制，不会上传。

**备份中途拔卡或 SSD 断开会怎样？**
已经校验完成的文件不受影响，没拷完的临时文件会被清理。重新插上后会从断点继续，不会重复拷贝。

**SSD 空间不够？**
Offload 会在开始前检查空间，不够时不会动手，并提示还差多少。
